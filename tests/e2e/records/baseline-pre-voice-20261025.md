# 음성 병합 직전 기준선 (2026-10-25)

음성 PR 병합 직전의 main(카드 이끎까지 반영)을 텍스트 경로로 잰 값이다. 음성 병합 뒤 같은 명령으로 다시 재서 비교한다.

- 스택: `eval-text` 프로필(격리 스택, 실제 LLM은 주어진 키의 gpt-4o-mini, 테스트 API, 추적 끔)
- 오인용 채점기: 끔. 주어진 키로 열리는 모델 가운데 보정을 통과한 모델이 없다(#17).
- 실행 횟수: 평가셋 1회, 가상 세션 대본형·자율형 각 1회. 표본이 작으므로 차이는 방향만 본다.

## 다시 재는 법

```sh
make up PROFILE=eval-text ALLOW_API=1
make seed PROFILE=eval-text SEED_ARGS="--minutes 15" ALLOW_API=1
make eval PROFILE=eval-text ALLOW_API=1                      # 평가셋 전체(페르소나 포함)
make eval PROFILE=eval-text SUITE=persona ALLOW_API=1        # 페르소나 품질
make measure PROFILE=eval-text MODE=scripted ALLOW_API=1     # 가상 세션 대본형
make measure PROFILE=eval-text MODE=autonomous ALLOW_API=1   # 가상 세션 자율형
```

원 기록: `eval-live-20261025-0819.md`, `eval-live-persona-20261025-082514-run.md`. 가상 세션 기록(`virtual/20261024-2307-scripted`, `virtual/20261024-2319-autonomous`)은 git이 무시하는 폴더라 커밋하지 않는다. 아래 표가 그 요약이다.
